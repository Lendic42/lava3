# Практическая работа 3 — ввод и вычисления

Учебная программа на C для практики ввода чисел, арифметических операций, форматированного вывода и функций.

## Задания

| Часть | Что делает программа |
| --- | --- |
| 1 | Читает два целых числа и показывает сумму, разность, произведение, частное и остаток |
| 2 | Переводит английские и испанские дюймы в сантиметры |
| 3 | Печатает таблицу умножения, сложения и вычитания двух вещественных чисел |
| Домашнее задание | Считает плотность населения по площади территории и числу жителей |

## Домашнее задание — вариант 27: плотность населения

Введи площадь территории в квадратных километрах, затем число жителей. Площадь может быть дробной, число жителей вводится целым числом.

Например, ввод **50 10000** означает площадь 50 км² и 10000 жителей. Программа делит число жителей на площадь:

~~~c
плотность = число_жителей / площадь
~~~

В примере получится **10000 / 50 = 200.00 человек на км²**. Введи ненулевую площадь.

## Как вводить данные

Программа задаёт вопросы по очереди. Нажимай Enter после каждого ответа.

1. Два целых числа, например **2**, затем **7**.
2. Количество дюймов, например **10**.
3. Два вещественных числа через пробел, например **3 5**.
4. Площадь и число жителей для домашнего задания, например **50 10000**.

В первом задании первое число не должно быть нулём: программа делит второе число на первое.

## Пример перевода дюймов

Для 10 английских дюймов программа считает **2.54 × 10 = 25.40 см**. Затем она показывает второй пример с испанским дюймом из методички: **2.32166 × 10 = 23.22 см**.
