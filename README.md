# Практика 3

Открой `Практика_3.vcxproj` в Visual Studio и нажми Ctrl+F5. Задания идут по очереди: два целых числа, дюймы в сантиметры, таблица для двух дробных чисел.

В задании с дюймами добавлен испанский дюйм, как разрешает методичка. Альтернативу 2А с милями не включал.

Домашнее задание 27: ввести цены за килограмм конфет, печенья и яблок, затем купленные килограммы каждого продукта. Программа считает общую стоимость.
